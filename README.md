# CliPS-GMCM-Discussion
R code for the discussion of Malsiner-Walli et al. (2026) in TEST

This repository contains the R code to reproduce the 2-component Gamma mixture simulation and non-permutation rate calculations presented in:

Ausín, M. C. (2026). Comments on: CliPS: How to identify cluster distributions in Bayesian mixture models. TEST.

To run the code, ensure you have the GMCM package installed in R.
